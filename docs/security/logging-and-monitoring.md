# Logging and Monitoring

Log request IDs, service, environment, version, route template, status, duration, authentication outcomes, session changes, invitation and membership changes, access denials, throttling, worker failures and dependency failures.

Never log passwords, cookies, authorisation headers, raw tokens, reset links, invitation secrets, credentials or unnecessary personal data.

Define actionable alerts for authentication abuse, cross-Home attempts, elevated errors, queue backlog, backup failure, capacity risk, privilege changes and service unavailability.

# Incident Response Outline

1. Detect and record the incident.
2. Preserve relevant evidence and logs.
3. Contain affected credentials, sessions, services or releases.
4. Assess impacted Homes, users and data.
5. Eradicate the cause and patch safely.
6. Restore from tested sources where needed.
7. Communicate appropriately and meet legal obligations.
8. Complete regression testing and post-incident review.
9. Update standards, controls and monitoring.

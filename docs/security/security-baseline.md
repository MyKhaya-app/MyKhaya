# Security Baseline

Security is a release requirement and applies to design, code, build, deployment and operation.

## Standards

- OWASP ASVS 5.0.0, Level 2 minimum target
- OWASP Top 10:2025 awareness baseline
- OWASP API Security Top 10:2023
- OWASP Web Security Testing Guide 4.2
- OWASP Cheat Sheet Series
- OWASP Mobile Top 10 2024 for the mobile client
- UK NCSC Secure Development and Deployment Guidance
- UK NCSC Software Security Code of Practice and implementation guidance
- NCSC Cloud Security Principles when hosted services are introduced

ASVS is the measurable control baseline. The Top 10 lists are awareness documents and do not constitute complete verification.

## Core principles

Default deny, least privilege, server-side enforcement, explicit trust boundaries, defence in depth, secure defaults, minimal attack surface, fail closed and collect the minimum data required.

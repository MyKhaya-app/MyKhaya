# Secure Development Lifecycle

Every substantial feature requires security requirements, privacy review, abuse cases, authorisation analysis, data-flow review, failure behaviour, logging, security tests, dependency review, deployment impact and rollback planning.

CI must include formatting, linting, type checks, tests, secret scanning, dependency scanning, SAST, container scanning, Compose/IaC scanning and SBOM generation.

Before broad internet release, complete ASVS Level 2 review, WSTG-based testing, manual authorisation and session testing, restore testing and independent security review or penetration testing.

# Tone and Copy

Copy should be human, calm and concise. Use Home, People, Plans and Wish Lists rather than technical product language.

| System language | Family language |
|---|---|
| Household members | Your family |
| Home Administration / Control Centre (household-facing) | Manage your home |
| Upcoming | Coming up |
| Quick actions | Around the house |

Empty states should be reassuring, not a report of zero rows — rotate
between a small set (see `visual-identity.md`) rather than always showing
the same line.

Notifications should describe the useful event directly, for example: “Megan added four items to Shopping.” Avoid robotic titles, technical errors and corporate language.

Error messages should explain what happened and the safe next step without blaming the user or exposing internal detail.

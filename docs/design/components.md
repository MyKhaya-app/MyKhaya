# Component Standards

Cards use soft surfaces, moderate rounding, subtle borders or shadows and clear hierarchy. Buttons use sage for primary actions, understated secondary surfaces and visible focus states. Forms use comfortable spacing, clear labels and calm validation messages.

Icons follow the simple outlined style shown in the canonical reference. Status colour must never be the only signal. Motion should be restrained and respect reduced-motion preferences.

Empty states should be reassuring and useful, not technical. Avoid dense tables unless the content genuinely requires one.

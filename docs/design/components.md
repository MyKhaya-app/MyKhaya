# Component Standards

> See `visual-identity.md` for the reasoning behind these values (the
> Version D refinement round) — this file is the quick implementation
> reference.

Cards use a soft shadow-lift rather than a visible border: 20–22px radius,
generous internal padding (~18px), warm white or linen fill against the
cream page background. No visible grey border. Buttons use sage for primary
actions, understated secondary surfaces and visible focus states. Forms use
comfortable spacing, clear labels and calm validation messages.

Avatars are a first-class element, not a small decorative afterthought —
size them generously (header avatar and any "family strip" should read as
clearly as the primary heading next to them). Each family member has one
colour, used consistently on their avatar and on their items across
Calendar and any future per-person list — see `visual-identity.md`.

Icons follow the simple outlined style shown in the canonical reference. Status colour must never be the only signal. Motion should be restrained and respect reduced-motion preferences.

Empty states should be reassuring and useful, not technical — and should
vary rather than repeat the same static string every time (see the rotating
set in `visual-identity.md`). Avoid dense tables unless the content
genuinely requires one.

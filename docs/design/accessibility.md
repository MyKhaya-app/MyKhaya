# Accessibility

Target WCAG 2.2 AA for web interfaces.

- Full keyboard operation
- Visible focus indicators
- Appropriate contrast
- Semantic landmarks and headings
- Accessible names and error relationships
- Touch targets suitable for mobile
- Screen-reader announcements for meaningful updates
- No colour-only status communication
- Reduced-motion support
- Responsive text and zoom support

Accessibility is part of acceptance criteria, not a final polish step.

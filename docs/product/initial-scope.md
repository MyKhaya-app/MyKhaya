# Initial Scope

The first implementation establishes the platform rather than the full feature set.

## Included

- Repository and standards
- Docker-based local and VPS deployment
- Next.js web shell
- Expo mobile shell
- FastAPI API
- PostgreSQL, Redis, worker and scheduler
- Registration, verification, sign-in, reset and session management
- Home creation, membership and invitations
- Responsive Home, People and Settings screens
- CI, migrations, logging, health checks, backup and restore guidance

## Deferred

Calendar, Tasks, Shopping, Meals, Plans, Wish Lists, notifications and external sharing are documented as future domain modules but are not fully implemented in the foundation iteration.
